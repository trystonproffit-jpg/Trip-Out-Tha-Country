# Trip Out Tha Country

Travel planning research for a 2027 international trip from the Greenville, South Carolina area.

The project compares affordable destinations, flight routes, estimated total costs, airports, booking thresholds, and Colombia/Guatemala flight deals.

## Files

- [`index.html`](index.html) — Main page for Netlify or any static host.
- [`trip-opportunities-2027.html`](trip-opportunities-2027.html) — Named copy of the HTML planning page.
- [`trip-opportunities-2027.md`](trip-opportunities-2027.md) — Agent handover document and working source of project context.

## Deploy with Netlify

1. Create or open a Netlify site.
2. Choose **Add new project → Import an existing project**.
3. Select this GitHub repository and the `main` branch.
4. Leave the build command blank and use the repository root as the publish directory.
5. Deploy the site.

Netlify will automatically redeploy after changes are pushed to `main`.

## Update the site

Edit the Markdown and HTML files locally, then commit and push:

```bash
git add .
git commit -m "Update trip research"
git push
```

For the deployed page, make sure changes are reflected in `index.html`.

## Important note

Flight prices are temporary search results and planning estimates, not guaranteed fares. Recheck the airline checkout price, baggage fees, lodging, entry requirements, and travel advisories before booking.
